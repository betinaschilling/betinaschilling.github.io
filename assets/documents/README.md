# Documentos públicos

Este diretório recebe documentos públicos disponibilizados pelo ComuniDados.

## Currículo

Nome canônico:

```text
curriculo-cheila-betina-schilling.pdf
```

Antes de substituir ou publicar o arquivo:

- confirmar que a assinatura do arquivo é `%PDF`;
- abrir e revisar todas as páginas;
- conferir nome, experiência, formação e contatos;
- remover endereço, documentos, telefone ou outros dados não destinados à publicação;
- atualizar a data, o tamanho e os links em `curriculo.md`.

Não usar arquivos placeholder com extensão `.pdf`.
